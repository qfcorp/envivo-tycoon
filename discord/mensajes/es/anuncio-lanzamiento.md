# Anuncio de lanzamiento (para copiar y pegar)

**Dónde:** canal 📢┃anuncios. **Cómo:** abre este archivo en GitHub, toca el botón **Copiar** del recuadro, pégalo en Discord y cambia lo que está entre [corchetes].

- Para que un canal quede como enlace azul, borra el nombre y escribe `#`, luego elige el canal de la lista.
- Para la hora usa https://hammertime.cyou : eliges fecha y hora y copias el código `<t:...:F>`; cada persona la ve en su propia hora.
- Después de publicar, toca **Publicar** (Publish) para que llegue también a los servidores que siguen el canal.
