# 🔗 Link your game account
Connect your production company to Discord to get your roles automatically.

**Step by step:**
1️⃣ In the game, open your account and tap **Link Discord**. You'll get a **code** (it expires in a few minutes).
2️⃣ In this channel type `/vincular` and paste the code into the **codigo** box.
3️⃣ Done! The bot replies with a message only you can see and gives you your roles.

**Roles you can get:**
{@&verificado} · your game server · {@&vip} (while your VIP Pass is active) · {@&comprador} · {@&presidente}
Your roles update automatically if you change server or association, or your VIP expires.

**Safety:**
🔒 The code is **only** used with `/vincular` on this server. Never send it to anyone by DM.
🔒 Never type your password or email here. The bot will **never** ask for them.
🔒 If someone asks for your code, it's an account theft attempt: report it in {#soporte}.

Trouble? Make sure the code hasn't expired and generate a new one. Still stuck? Open a post in {#soporte} with the **Vincular Discord** tag.
